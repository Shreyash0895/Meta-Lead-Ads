# Frontend React Native App Guide

## 1. Installation
```bash
npm install
```

## 2. Configuration
Open `App.js` and set `BACKEND_URL` to your active Ngrok URL:
```javascript
const BACKEND_URL = 'https://xxxx.ngrok-free.app';
```

## 3. Run Application
For iOS Simulator:
```bash
npx react-native run-ios
```
For Android Emulator:
```bash
npx react-native run-android
```
